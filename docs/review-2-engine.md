# 2차 독립 검토: 계산·체결·장애

검토일: 2026-10-19. 엔진 구현 담당과 분리된 검토자가 엔진·성과 감사 코드를 읽고, 손계산과 결과 변조·미래 가격 변경을 직접 검사했다. 모든 테스트 입력은 **합성 가상 데이터**이다. 실제 시장 전략의 수익성을 검증한 결과가 아니다.

## 실행 결과

검토 환경의 기본 `python -m pytest`에는 pytest가 없어 실행하지 못했다. 이는 테스트 실행기 경로 문제이며 애플리케이션 assertion 실패가 아니다. 실제 설치 환경의 명시적 경로로 다시 실행했다.

```bash
cd /workspace/stock-auto-trader
PYTHONPATH=src python -m unittest discover -s tests -p test_engine.py -v
/workspace/.venvs/stock-validator/bin/python -m pytest tests/test_review_engine.py tests/test_engine.py -q
```

첫 실행은 엔진 unittest **22개 통과**, 두 번째 실행은 엔진 22개와 독립 리뷰 5개, 총 **27개 통과**였다. 독립 리뷰에는 결정적 난수 20개 경로의 다종목 갭·낮은 거래량·부분 체결 원장 재구성이 포함된다. 이 문서의 숫자는 이 검토자가 직접 실행한 범위이며 전체 프로젝트 테스트 수와 다르다.

## 독립 손계산

초기자금 10,000원, 매수·매도 수수료 각 1%, 매도세 2%, 슬리피지·환전비용 0의 가상 예제다. 100원에 99주를 사면 원가 9,999원, 현금 1원이다. 110원에 49주를 부분 매도하면 비용 차감 대금은 5,228.30원, 배분 원가 4,949원, 실현손익 279.30원이다. 나머지 50주를 120원에 매도하면 대금 5,820원, 실현손익 770원이다. 최종 현금은 **11,049.30원**, 거래손익은 **1,049.30원**, 순수익률은 **10.493%**, 종가 최대낙폭은 매수수수료에 따른 **-0.99%**다. 프로그램의 각 시점 현금·보유평가·실현·미실현손익과 별도 성과 계산이 이 값에 일치했다.

별도 엔진 손계산은 달러 9주, 매수 환율 1,000원/달러, 청산 환율 1,200원/달러와 왕복 수수료·세금·슬리피지·환전비용을 검사한다. 진입 원가 92,718원, 순손익 30,453.84원, 최종 순자산 130,453.84원의 assertion이 실제 실행에서 통과했다. 이는 환율 계산 단위의 검증이며 당일 실행 환율을 확보했다는 뜻이 아니다.

## 확인한 체결·위험 동작

- 손절과 익절을 한 봉이 모두 통과하면 손절을 먼저 적용한다. 갭 하락은 손절가보다 불리한 시가로 청산할 수 있다.
- 매수 예정수량은 직전 봉 거래량과 비용 포함 계획 손실/현금으로 제한하고 실제 매수·매도는 같은 봉의 수량 예산을 공유한다. 미체결 진입은 오래된 주문으로 다음 날 재시도하지 않는다.
- 손절 청산의 미체결 잔량은 유지한다. 거래정지와 거래량 0이면 억지 청산하지 않고 미청산 보유분을 기록한다.
- 부분익절의 잔존 원가와 전체 거래손익을 추적한다. 보유기간은 해당 종목 봉으로 세며 후행손절은 다음 봉부터 적용한다.
- 일간 2만원은 UTC 날짜 시작 직전 순자산 대비 감소를 기준으로 신규 진입을 막는다. 전략 5만원은 고점 대비 낙폭, 계좌 100만원은 초기자금 대비 손실로 별도 관리한다. 이 해석은 결과와 사용자 문서에 명시해야 한다.
- 의사결정 이후 가격을 크게 변경해도 이미 완료된 시점의 체결과 순자산은 바뀌지 않는다. 당일 종가 FX는 같은 봉 시가 매수에 사용하지 않는다.

## 미해결·범위 제한

이 단계에서 확인한 재현 가능 계산 결함 D11과 R2-1은 수정 후 해당 테스트를 통과했다. 이번 27개 검사 안에 미해결 assertion 실패·skip은 없다. 아직 실행하지 않은 전체 테스트와 실제 시장·웹·보안 검증은 3차 검토 및 최종 실행 결과로 별도 보고해야 한다.

일봉 거래량 참여율은 시가 유동성과 주문 대기열의 근사치다. 실행 환율은 직전 종가 관측을 사용한다. 세금과 비용은 연구 가정이며 시장별 현행 법정 세율을 인증하지 않는다. 기업행동·PIT 유니버스·실제 상장폐지 처리는 증거 부족으로 자동 합격을 차단한다. 실제 분봉·호가·기업행동을 확보하지 않고 이 제한이 해결됐다고 주장해서는 안 된다. 갭·환율·거래정지로 실제 손실이 계획 손실보다 커질 수 있다.
