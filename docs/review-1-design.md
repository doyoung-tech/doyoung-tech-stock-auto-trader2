# 1차 독립 검토: 설계·데이터·논리

검토자: 구현 담당과 분리된 설계 검토 에이전트. 대상: `docs/ARCHITECTURE.md`, `src/stock_validator/models.py`와 개발 중인 데이터·전략·검증·체결 계약. 작성일: 2026-10-19. 초기 설계와 후속 구현의 정적 검토를 수행했으며, 아래 D11 한 건은 독립 재현했다. 실행되지 않은 테스트의 통과를 의미하지 않는다.

## 판단

실제 주문과 연구 엔진을 분리하고, 의사결정 봉 다음 봉부터 체결하며, 합성 데이터와 증거 부족 데이터를 합격에서 제외하는 방향은 요구와 일치한다. 다만 검증 가능한 과거 구성종목·기업행동·발표 당시 재무·실행 시점 환율 자료가 없는 상태에서 자동 합격을 내리면 안 된다. 수집된 가격 데이터로 연구 수치를 계산하는 것과 투자 가능한 전략을 검증했다는 판단은 별도이다.

## 최소 증거 계약 제안

확장 가능한 증거 manifest에는 스키마 버전, 원자료의 SHA-256, 출처 URI/이용조건, 파일 종류·해시·관측 기준일, 커버리지 시작/종료 시각을 기록한다. 다음 자료의 실제 레코드를 검사하는 기능이 있어야 bool 이상의 근거가 된다.

- 과거 종목 구성: 종목, 상장·상장폐지, 구성 유효 시작/종료, `known_at`.
- 기업행동: 종목, 이벤트 종류, 효력 시각, 공개 시각, 분할 비율/현금/통화.
- 당시 재무·전망: 회계기간 종료, `available_at`, 발표 당시 원값과 출처. 사후 수정치의 원발표 소급 금지.
- 과거 업종 구성과 업종지수; 벤치마크의 통화·총수익/가격지수 구분.
- 환율: 통화쌍, 관측 시각, 적용 가능한 체결 시각, 원출처.

이 구조는 권고이며 현재 완성·수집되었다는 주장이 아니다. 포괄적 이력 자료를 검증하지 못하는 초기 버전이 자동 합격을 차단하는 것은 요구에 맞는 보수적 결과다.

## 검토 방법과 남은 확인

설계·모델·전략·지표·데이터 loader·초기 엔진·성과 회계를 정적으로 검토했다. A~F는 미래 봉을 방어적으로 제외하고, D/E는 `period_end <= available_at <= decision_time`을 지키며, F는 동일 과거시점의 업종·벤치마크 입력을 요구한다. 종목별 보유봉 계수와 직전 관측 FX 적용도 코드로 확인했다.

독립 재현은 D11 한 건이다. 가상 X 종목 3봉(100/100, 100/100, 시가 200·종가 100), 비용 0, 부분익절/후행손절 없음, 먼 목표가 조건에서 종가 순자산은 그대로지만 기록 낙폭은 -20%, 별도 성과 MDD는 0%, `independent_audit`는 낙폭 불일치로 실패했다. 이는 전략 실적이 아니라 엔진 결함을 찾기 위한 합성 검사다. 후속 수정에서 위험 고점과 성과 종가 고점을 분리했고, 해당 회귀검사를 포함한 엔진/독립 리뷰 27개 테스트가 2차 검토 실행에서 통과했다.

후속 정적 확인에서 실제 자동 합격 차단, 정확히 같은 원관측 자료의 고정 holdout 레지스트리, E 전용 장기 표본 정책을 확인했다. 단일 시장을 넘는 날짜 union의 purge 단위와 자료 개정 간 holdout 기간 계보는 별도 제한으로 남아 있다. 손계산·부분체결·장애 테스트는 2차 검토에 넘긴다. 실제 시장 자료의 기간·출처·품질 한계와 모든 실행 테스트 통과/실패는 별도 로그 및 최종 보고서에 남긴다.
