# 연구 전용 전략 검증 플랫폼 설계

Python 3.12. 실행 주문·증권사 연결·AI 예측 없음. 원본·정제 데이터, 실험 결과, 사전 합격 기준의 해시를 보존한다. `models.py`가 모듈 간 계약이다.

## 결정과 체결

모든 Bar 시각은 UTC aware datetime, 해당 봉 마감시각이다. 봉 t까지의 불변 이력으로 결정하고 t+1 시가부터 체결한다. 재무자료는 available_at <= t이고 period_end <= available_at인 발표 당시 수치만 사용한다. 현재 업종/현재 구성종목을 과거에 소급하지 않는다. 원시가격의 분할/배당 미확인은 합격 차단. 조정 OHLC 제공처의 사후 조정 한계도 공개한다.

KRW 기준 현금+보유 평가액=순자산, 초기자금+실현+미실현=순자산을 매 봉 확인한다. 비용은 주문당 수수료·매도세·슬리피지·환전 비용을 각 체결에 반영한다. 비용 기본치는 보수적 연구 가정이며 현행 세율을 보장하지 않는다. 정수 주식·매수 가능 현금·거래량 제한. 봉 내 손절과 익절 순서 불명은 손절 우선. 갭은 불리한 시가 적용, 거래정지/거래량 부족시 미체결·부분체결, 잔량과 미완결 포지션을 표시한다. 장 마감 최종 평가도 거래정지를 강제 체결하지 않는다.

## 위험과 평가

초기 100만원, 비용 포함 계획손실 1만원, 당일 순자산 감소 2만원이면 신규 진입 중단, 최고 순자산 대비 5만원 손실이면 전략 중단, 계좌 전체 100만원 한도 별도. 갭·유동성 부족 시 실제 손실 초과 가능. 신용·레버리지·공매도 없음.

A/B/C/D/F 최대 1~5거래일, E 252~1260거래일. E는 독립 장기 정책과 표본 기준으로 평가한다. 고정/ATR 손절, 고정/손익비 목표, 부분익절, 후행손절과 시간청산을 분리한다.

개발/반복 워크포워드/최종 미사용 holdout을 시간순 분할한다. 경계는 보유기간만큼 purge/embargo한다. 최종 holdout은 선정 후 한 번만 개봉하고 실험 레지스트리로 재사용을 차단한다. 비용 2배, 인접 파라미터, 시장국면, 부트스트랩 불확실성, 다중검정 보정 결과까지 사전 기준으로 평가한다. 데이터 근거/표본/테스트가 부족하면 데이터 부족, 성과/위험 기준 미달은 불합격. 합격도 실전 자동활성화 없음.

## 모듈

- `engine.py`: 결정·체결·회계·위험관리 (`run_backtest(dataset, strategy, config)`).
- `strategies.py`, `indicators.py`: A~F 신호, 불변 과거 이력만 사용.
- `data.py`: 합법적 공개 일봉/사용자 CSV, provenance, 정제·품질 검증. 확보 실패는 실패로 기록.
- `validation.py`, `metrics.py`: 독립 성과 계산, 실험 레지스트리·사전 기준·3단계 평가 (`validate_dataset(dataset, output_dir, policy_path)`).
- `web.py`, `static/`: 읽기 전용 한국어 모바일 보고서. 외부 주문·임의 파일 경로·원격 실행 API 없음.
- `cli.py`: 수집, 명시적 합성 데모, 검증, 서버.

실제 데이터 부재를 합성으로 보충하지 않는다. 합성 데모는 별도 저장·라벨링하며 절대 합격하지 않는다. 현재 구성종목만 다운로드한 데이터는 생존자 편향 통제 불가로 합격 차단. 분봉·상장폐지·PIT 전망·과거 대형주 이력이 없으면 지원 인터페이스/제한을 명시하고 수집했다고 주장하지 않는다.
