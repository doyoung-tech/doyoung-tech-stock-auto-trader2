# 데이터 수집·검증과 현재 한계

실제 데이터와 가상 테스트 데이터는 별도 디렉터리·manifest의 `synthetic`으로 구분한다. 네트워크 실패 시 `collection.json` 실패 기록만 남기며 가상 가격을 대신 생성하지 않는다. 데이터 수집 성공은 검증 합격을 의미하지 않는다.

## 현재 실제 접근 결과

2026-10-19 최초 읽기 요청에서는 `query1.finance.yahoo.com`·`stooq.com`·`fred.stlouisfed.org`·`fchart.stock.naver.com`·`data.krx.co.kr`·`data.sec.gov`가 프록시 CONNECT `403 Forbidden`으로 차단됐다. 환경 네트워크 상태가 변경된 뒤 실제 어댑터를 실행하자 Yahoo·FRED 응답을 확보했다. TLS 검증은 유지했다. 설정 저장만으로 성공이라 주장하지 않고 실제 응답 원본·체크섬을 확인했다. 민감정보 없는 확인 내역은 [data-access.json](data-access.json)에 기록한다.

- **한국 실제 연구 데이터** `data/real-kr`: 삼성전자 4,126봉·SK하이닉스 4,124봉, 총 8,250봉. 주 벤치마크 코스피는 4,126봉. 실제 관측기간 **2010-01-04~2026-10-16**. 코스닥 4,127봉은 원본 대체 벤치마크 자료로만 보존하며 코스피와 섞지 않았다. 현재 선택한 두 종목이므로 시장 전체나 상장폐지 종목을 대표하지 않는다.
- **한국 원본 문제**: 종목 2개의 2025-09-19, 코스피 2011-10-04·2015-08-14는 전체 OHLCV 결측이다. 삼성전자 2024-10-14, SK하이닉스 2023-02-02·2023-02-09·2024-10-14는 원본 종가가 고저 범위 밖이다. 이 **8개 종목별 세션**을 원본값과 사유 그대로 격리하고 `missing_sessions.csv`에 기록했다. 가격을 고치거나 보간하지 않았다. 코스닥의 별도 2015-08-14 결측은 대체 원본 수집 기록에 있다. 휴장·거래정지·공급 오류 중 어느 원인인지 단정하지 않는다.
- **미국 실제 가격** `data/real-yahoo`: SPY와 S&P500(`^GSPC`) 각각 4,223봉, **2010-01-04~2026-10-16**. 실제 시점에 이용 가능한 원/달러 환율이 없어 원화 수익률을 계산하지 않는다. 현재 원래 수집본은 두 기호가 모두 가격 테이블에 있으므로 그대로 투자 모집단으로 쓰지 않는다. 재수집 시 `--symbols SPY --benchmark '^GSPC'`로 분리한다.
- **FRED 환율**: **2010-01-04~2026-10-09** 실제 DEXKOUS 관측 CSV 4,375행(양의 숫자 4,196행·결측 179행)을 확보했으나 공개 가능 시각이 없으므로 체결용 환율로 투입하지 않았다. 결측 관측은 실제 숫자로 간주하지 않는다.
- **Stooq**: 실제 응답은 OHLCV CSV가 아닌 브라우저 검증 HTML이었다. 검증을 우회하지 않았고 가격을 확보했다고 표시하지 않는다. 원본 응답과 실패 기록을 보존했다.

원본 일봉은 연구용 후보 자료이며 생존자 편향·가격 조정·기업행위 회계·PIT 공시가 검증되지 않아, 16년 이상 기간을 확보했어도 전략 합격을 뜻하지 않는다. 원본 데이터와 가상 데모 데이터는 Git에서 제외하며 이용권한을 확인하지 않은 외부 가격 데이터를 저장소에 재배포하지 않는다.

동일 한국 자료 전체기간을 엔진 통합 점검에도 사용했다. 자동 시간분리는 구현했지만 이번 결과를 엄격하게 블라인드 상태로 보존한 최종 독립 검증이라고 주장하지 않는다. 전략 수익성을 인정하려면 새로 확보한 미사용 기간과 완전한 데이터 감사가 필요하다.

## 지원 수집 경로와 권한

- Yahoo 일봉: `query1.finance.yahoo.com/v8/finance/chart`, 한국 `.KS`·`.KQ` 및 미국 종목. 비공식/문서화되지 않은 공개 엔드포인트이며 제공처 이용약관·개인 연구 권한을 사용자가 확인해야 한다. 공개 접근은 라이선스 부여가 아니다. 원본 응답·조회 URL·수집 시각·파일별 SHA-256·실제 시작/종료일·봉 수를 보존한다. 가격 조정 방식·기업행위 완전성을 보증하지 않는다.
- Stooq 일봉: `stooq.com/q/d/l/`, `.US` 종목 및 미국 대표지수 기호만 지원한다. 거래량이 없는 응답은 매매 시뮬레이션에 사용하지 않는다. 조정가격·폐지종목 포함범위·재배포 권한은 별도 확인해야 한다.
- FRED DEXKOUS: 미국 연방준비은행의 공식 원/달러 관측값 CSV 다운로드 함수를 제공한다. 관측일은 실제 공개시각이나 체결가능 환율과 다르므로 다운로드만으로 원화 백테스트에 투입하지 않는다. 휴일·발표 지연·환전 비용·체결 시각을 별도 처리해야 한다.
- 공식 한국 주식/공시: KRX Open API·공공데이터포털 API·DART는 제공처별 이용신청/키/기간 제한을 확인해야 한다. 키를 요구하거나 결제하지 않았다. SEC companyfacts는 공식 공개자료지만 접수 시각·정정 이력·당시 이용 가능 버전을 검증하는 별도 수집기가 필요하다. 이번 버전에는 SEC/DART 수집기와 전망치 제공자가 없다.

1·10·60분봉, 10년 이상의 전 종목 이력, 상장폐지·거래정지·종목코드 변경, 실제 PIT 전망치/대형주/업종 구성 이력을 확보하지 못했다. 현재 종목만 모으면 생존자 편향을 제거할 수 없다. 무료 제공처의 장중 제한을 우회하거나 허가가 불명확한 미러에서 데이터를 복제하지 않는다.

## 감사 가능한 CSV 형식

데이터셋 디렉터리는 필수 `prices.csv`, `manifest.json`과 선택 `benchmark.csv`, `sector_bars.csv`, `fundamentals.csv`, `sectors.csv`를 포함한다. CSV는 UTF-8, 아래 열 순서를 사용한다. `save_dataset`은 기존 비어 있지 않은 경로를 덮어쓰지 않는다. `load_dataset`은 파일별 체크섬과 전체 CSV 체크섬을 확인하며 경로 이동·심볼릭 링크를 거부한다. 체크섬은 변조 탐지 도구이고 원본 사실의 진위 보증은 아니다.

가격·벤치마크·업종 가격 열:

```csv
timestamp,symbol,open,high,low,close,volume,currency,fx_to_krw,tradable
```

`timestamp`는 봉 마감시각을 나타내는 UTC aware ISO 8601이다. 가격은 양수·유한, 거래량은 0 이상·유한, 저가≤시가/종가≤고가여야 하며 `(timestamp,symbol)` 오름차순·유일해야 한다. KRW의 환율은 1이다. USD에서 실제 환율이 없으면 빈값으로 저장하고 `prices_only=true`로 제한한다. 이를 1로 대체하지 않으며 엔진은 원화 성과를 차단한다. Yahoo 일봉은 정규장 명목 마감시각으로 변환한다. 미국 조기폐장은 정규장 마감으로 늦게 알았다고 처리하며 정확한 분봉 체결·과거 장시간 변경은 구현하지 않았다.

별도 환율 입력은 `available_at,fx_to_krw` CSV이다. `available_at`은 관측일이 아닌 실제 공개 가능 시각으로 시간대가 필요하다. 해당 봉 마감까지 알려진 양의 실제 환율 중 최근 7일 이내 값만 선택한다. 다음 봉 시가 체결에는 엔진이 직전 봉의 알려진 환율을 사용해야 한다. 이 보수적 환율은 실제 환전 호가를 보증하지 않는다. 원본 환율 파일도 체크섬과 함께 저장한다.

전체 OHLCV가 결측이거나 원본 가격/거래량 범위가 잘못된 Yahoo 세션은 `missing_sessions.csv`의 `symbol,timestamp,reason`에 기록하고 유효 가격 테이블에서 격리한다. 원본과 `collection.json`에 정확한 값·사유를 보존한다. OHLCV 일부만 빠진 불완전 행은 수집 실패로 처리한다. 알려지지 않은 세션을 거래정지로 단정하거나 가격을 보간하지 않는다. 엔진은 미확인 결측으로 넘어가는 주문을 취소하고, 이전 가격을 새 관측값인 것처럼 신호에 추가하지 않는다. 데이터 전체 무결성은 여전히 부족하므로 합격을 차단한다.

재무 열:

```csv
symbol,available_at,period_end,revenue_growth,earnings_growth,forecast_revision,debt_to_assets,profitable,market_cap_krw,formerly_large_cap,source
```

`available_at`은 실제 발표 당시 수치의 공개 시각이며 `period_end` 이후여야 한다. 날짜만 있는 공시는 시각을 임의 발명하지 않는다. 정정 재무는 정정 공개시각에 별도 행으로 추가한다. 현재 전망치·현재 시총을 과거에 소급하지 않는다. bool은 `true/false`, 미확인 선택값은 빈칸이다. 발표시각·종목·기간 순으로 유일해야 한다.

업종 소속 열은 `symbol,effective_from,effective_to,sector`이며 유효기간은 `[from,to)`이다. 현재 소속으로 과거를 메우지 않는다. 단순 유효일만으로 당시 알려진 소속을 증명할 수 없으므로 PIT 품질을 자동 인정하지 않는다.

## 품질 판정과 의도적인 합격 차단

manifest의 `meta`에는 출처, aware `retrieved_at`, `synthetic`, 가격 기준, 라이선스 메모, 제한, 각 품질 플래그, 전체 CSV SHA-256이 필요하다. 전체 해시는 이름순 CSV의 `파일명 + NUL + 바이트 + NUL`을 SHA-256으로 계산한다. `files`는 모든 데이터·원본 파일에 대해 파일명→SHA-256을 기록한다.

사용자가 `corporate_actions_complete`·`survivorship_bias_controlled`·`point_in_time_universe`·`point_in_time_fundamentals`·`sector_history_complete`를 true로 선언해도, 이번 버전의 importer는 false로 낮춘다. 선택 `evidence`의 체크섬 증빙이 있어도 레코드 의미·포함범위와 분할/배당/상폐 현금흐름을 교차 검증하는 코드가 아직 없기 때문이다. 원본 선언은 manifest에 보존하고 다운그레이드 이유를 결과에 남긴다. **이 버전은 실제 데이터의 자동 합격을 허용할 완전한 감사 수집기를 구현하지 않았으며, 안전한 연구 진단과 부족 데이터 식별에 한정된다.** 완전한 PIT/기업행위 수집·회계 검증은 다음 개발 단계다. 가상 데이터도 항상 합격 차단한다.
